# Vanguard client design
Extend the existing TypeScript/Node 24 source-client architecture with Etymology Explorer at the user-confirmed https://api.etymologyexplorer.com/staging base URL, without provider authentication. Validate the supplied autocomplete schema, preserve bounded JSON for undocumented data envelopes, and retain the exact request URL and retrieval timestamp. Do not infer confirmed roots from search matches or invent response fields, revision IDs or data reuse permissions.
Expose documented data reads through a library, CLI, bounded stdio MCP, and the established authenticated local API on port 4323. Provider credentials are unnecessary; local control authentication and in-memory credential rotation remain compatible with the fleet.
Use single numeric IDs and the documented direction ance/random type root until other argument conventions are verified. Defer pronunciation (media contract unknown) and error-list (non-research operation). Enable the implemented service in the orchestrator without adding unrestricted tools to the root research workflow.
Approach: adapt the shared bounded transport/host, rather than guessing schemas or scraping website internals. The user's explicit request to proceed authorizes this established architecture.
